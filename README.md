严格要求
1. 所有内容必须严格基于  ，不得引入论文之外的知识、背景资料或个人推测。
2. 论文没有明确提供的信息，统一填写：“文中未明确说明”。
3. 不得为了填满字段而自行推导“创新性”“研究价值”“学术对话”或“未来研究方向”。
4. 必须区分：
    * 核心发现＝研究实际得到了什么结果；
    * 结果阐释＝作者如何解释这些结果；
    * 学术对话＝作者如何把结果与已有研究或理论联系起来；
    * 最终结论＝全文最终得出了什么结论。
5. 核心发现优先保留原文中的关键数据、效应方向、统计结果、主题名称和重要关系，不要只写笼统总结。
6. 如果论文不是实验研究，不要强行使用“实验对象、实验材料”等框架，应根据实际研究类型进行概括。
7. 若论文某一字段存在多个要点，请分点呈现；没有必要为了形式统一而固定条目数量。
8. 输出前再次核对论文，重点检查：
    * 是否出现论文中不存在的信息；
    * 数字、样本量、年份、研究对象是否准确；
    * 是否把作者的讨论或推测误写成研究结果；
    * 是否遗漏论文最主要的研究发现。

### 可直接使用的提示词

请阅读本次指定的论文全文，参照速读文献模版及 JIBS 整理示例，形成能用于快速理解、比较、向导师汇报和后续精读的中文文献表格。整理后应让读者能够回答：为什么研究、具体研究什么、如何获得证据、得到了哪些发现、作者如何解释，以及相对既有研究推进了什么。具体执行以下要求。

#### 1. 阅读范围与证据要求

1. 通读摘要、引言、理论与假设、方法、结果、讨论、局限及结论，并核对与主要发现相关的图表、表注和可读取的附录。遇到文本提取不完整时，查看对应 PDF 页面，尤其注意扫描页、双栏错序和表格数字。
2. 先在内部建立“字段、原文依据、页码或章节”的对应关系，再概括输出。无需把内部核对过程逐项展示在最终表格中。
3. 一个字段的信息可能分布在多个章节。不要因缺少同名小标题而判定该字段没有内容。例如，贡献可以在引言或讨论中提出，未来研究建议可以出现在局限段落中。
4. 所有概括均以当前论文为依据。允许合并分散表述、准确翻译和压缩复述，不得自行提出作者未讨论的机制、贡献、局限或未来方向。论文引用的其他研究只整理本文对它们的讨论，不表示已阅读被引文献全文。
5. 不把模版中的内容直接套用到新论文。论文类型、研究对象、变量名称、样本量及统计结果均须逐篇核对。同一论文的不同副本应通过标题、作者、DOI 和版本信息识别，统一核对依据；保留用户已有编号，不擅自删除重复编号。
6. 不把 Excel 的“PDF转文本”单元格视为完整全文。Excel 单元格最多容纳 32,767 个字符；文本达到此长度、结尾突然中断、缺少后部章节或页码不连续时，应返回原始 PDF 分页读取并核对阅读范围。“AI解析”及“输出结果”属于二次整理，也不能替代原文证据。
7. 在内部先梳理“研究缺口、理论基础、核心概念及关系、研究设计、主要证据、贡献”的对应关系。多研究论文标明每项研究负责回答什么问题；定量论文对应 RQ/H 与结果，质性论文对应主题与过程，理论论文对应概念与命题。最后再按固定栏目组织语言，不新增用户未要求的列。

1. 更新已有 `document.md` 时，保留其现有列名、列顺序和未指定修改的条目，将下述要求对应到同名栏目。用户另有明确要求时，以用户要求为准。
2. 新建表格时，按模版的业务栏目顺序排列，首列增加“序号”：
   序号、英文标题、上传英文PDF、中文标题、作者、期刊、年份、背景与动机、研究问题、研究价值、摘要、关键词、研究方法、核心发现、组织逻辑、结果阐释、学术对话、局限性、创新性、未来研究方向、最终结论。

| 背景与动机 | 控制在 150 字以内，串联现实或理论背景、既有研究缺口与开展本研究的原因。优先说明已有解释为何不充分、哪些发现存在张力或哪些群体被忽略，避免用宏观背景挤占具体研究缺口。 |
| 研究问题 | 按原文研究目标、RQ 或假设分点，明确“研究谁、考察哪些关系、在哪种情境下”。有 RQ/H 编号时尽量保留，区分主效应、机制和边界条件。假设写成作者的预期，支持情况放入核心发现，不将一般研究意义混入研究问题。 |
| 研究价值 | 说明研究补充了哪类知识、回应了什么缺口，以及作者提出的理论或实践意义。可以归纳作者在不同章节提出的价值，避免“具有重要意义”等空泛表述。 |
| 摘要 | 准确概括原始摘要中的背景、目的、设计、主要结果和结论，形成连贯段落，保留摘要中最关键的数据与限定条件。与“核心发现”分工清楚，无需在此重复全部结果。 |
| 关键词 | 优先完整保留原始关键词及其英文拼写。没有作者关键词时留空，不把自行提炼的主题词冒充原始关键词。 |
| 研究方法 | 按“研究设计、数据与样本、变量测量或编码、分析与检验”组织适用信息。写清关键筛选条件、时间与层级、核心构念如何被测量，以及模型如何回答研究问题。对识别策略、稳健性或补充研究简要说明用途，避免只堆方法名称。多项研究分开交代，让读者能够理解每项研究具体如何完成。 |
| 核心发现 | 信息最充分的栏目。按原文研究问题、假设、研究阶段或结果主题分点，每点先用短语点明发现，再写具体关系、适用对象或条件及关键证据。覆盖主要结论、机制、重要不显著结果和边界条件；有助于判断结论可靠性的稳健性及补充结果可合并概括。区分描述性、基准模型与调整后结果，不只罗列系数或“支持 H1”。 |
| 组织逻辑 | 用简洁段落说明发现如何依次推进、回应问题或检验模型，并说明后一步为何需要前一步。依论文实际可写主效应到机制再到边界条件、多项研究间的递进或互补、质性过程的阶段与分岔、概念框架到命题的推演。保留本文独有的分析主线，避免罗列通用章节名称或强加固定顺序。 |
| 结果阐释 | 按主要发现对应整理作者的机制解释、情境原因与理论含义，说明为何得到该结果，特别注意反常结果与不支持假设的解释。指出相关理论名称及其在解释中的作用，避免只列理论名。使用“作者认为”“作者提出……可能”等必要语气，区分检验支持的机制与讨论中的可能解释。 |
| 学术对话 | 按“既有研究的具体观点或假设、本文的发现或论证、二者的关系及推进”分点。明确是支持、补充、修正、不同证据或扩展边界，写出对应理论或研究脉络。原文给出代表性作者与年份时，可简要保留，不自行补引文。避免只写“丰富了相关文献”，也不将单一情境的差异概括为推翻整个理论。 |
| 局限性 | 整理作者明确讨论的样本、设计、测量、平台、时段、因果识别或推广范围限制，按“具体限制及其对解释或推广的影响”表述。区分没有直接测量机制、无法区分竞争性解释与样本外适用范围受限等不同问题，不自行附加通用批评。 |
| 创新性 | 按原文能够支持的理论、机制、方法、测量、研究对象或场景贡献分点，写清相对于既有工作的具体推进。采用常见方法或更换研究场景本身不自动构成创新，需依据作者提出的实际贡献。“首次”“首创”“填补空白”等判断必须有原文依据，并保留其适用范围。 |
| 未来研究方向 | 提炼作者提出的具体后续问题、拟拓展的变量或情境、需改进的方法和待验证的关系。原文有依据时写出“待解决的问题、建议的对象或设计、希望检验的关系”，让建议具备可研究性。只整理作者建议，不将自行根据局限想到的方向补入。 |
| 最终结论 | 用连贯段落按“研究对象或情境、核心回答、重要边界、主要意义”收束全文，体现得到支持与未得到支持的关键关系。无需重复所有统计结果。结论强度不得超过核心发现，不把作者的机制猜测、管理建议或未检验的绩效影响写成已证实的效果。 |

详细程度以“能还原主要研究过程与结论”为准。参照 JIBS 示例，将篇幅重点放在方法、核心发现、结果阐释和学术对话。方法通常需要数百字交代研究流程，核心发现可用数百字分层展开；多研究或复杂过程模型可以更长，简单研究可以更短。这些仅作详细程度参考，不设置最低字数，不为统一长度删掉关键内容或重复凑字。其余栏目各司其职，使用“1. 主效应：……<br>2. 中介机制：……<br>3. 边界条件：……”等适合单元格阅读的表达；标签与顺序须服从当前论文。

#### 4. 研究方法与核心发现的进一步要求

1. **问卷与实验研究**：交代各阶段样本、时间间隔、操纵与分组、主要变量测量、分析模型，以及原文报告的关键中介和调节检验。多项研究分别说明，区分招募样本、有效样本和各模型分析样本。分别写清每项研究检验的关系及相互验证、扩展或不一致之处，不将不同研究的样本和系数混合。
2. **内容分析与社交媒体数据研究**：交代平台、账号或帖子抽样、数据时段、分析单位、编码维度、编码流程与信度、互动指标及模型。区分 CEO 数量、帖子数量和受众数量，区分点赞、转发、评论及标准化互动率。依据原文说明受众是员工、消费者、投资者、求职者还是一般公众，哪些背景特征被实际测量或检验，避免将公众互动直接解释为员工态度。
3. **档案、面板与准实验研究**：说明个体、企业、帖子、企业年度等观测单位及其层级，区分独立对象数和总观测数。交代处理与对照、事件时间或滞后、关键固定效应与识别检验；如采用 DiD、工具变量或匹配，写清作者如何使用及其要缓解的问题。区分稳健性、机制和拓展检验，不将使用这些方法概括为“已排除所有内生性”或“控制了全部混淆因素”。
4. **综述与荟萃分析**：交代检索范围与截止时间、纳入排除标准、研究及独立样本数量、效应量与合并模型、异质性和偏倚处理，保留重要亚组结果。区分个体、团队和组织层面的证据，不将某一层面的结果直接推广到其他层面。
5. **质性研究**：写明情境、案例或访谈对象、抽样、资料规模与时间、编码和归纳或溯因过程。发现中保留关键主题的含义、主题之间的联系、过程阶段、转折与分岔条件；分类研究说明划分依据及各类差异，过程研究说明如何从起点发展到结果。原文只有叙事证据时，不编造主题比例或显著性，也不将案例中的路径说成唯一决定因素。
6. **概念与理论论文**：研究方法说明理论整合、逻辑推演或框架建构的路径；核心发现整理概念定义、分类维度、命题、机制、过程及边界条件，尽量保留命题编号。始终使用“提出”“推演”“预期”等对应语气，最终结论也保持理论主张的证据性质，不写成实证验证。
7. **定量发现的基本表达**：采用“变量关系或组间差异＋方向＋关键统计证据＋适用条件”的表达，先说发现的实质含义，再给必要数字。优先保留与核心结论直接相关的系数、效应量、p 值、置信区间或比例，避免复制整张结果表；每个数字应能对应样本、模型、路径、时点或对照组。
8. **统计量与测量口径**：保留原文统计符号的含义，核实 B、b、β 是否标准化，区分相关系数、回归系数和间接效应。区分概率、优势比（OR）、风险比、百分比变化及百分点，OR 的变化不能直接改写为概率同比变化。明确真实构念与代理指标，例如测量用药、发帖互动或行为意向时，不直接等同于心理困扰程度、认同或实际行为。保持原文数值精度，不自行补算未报告的 p 值、置信区间或经济效应。
9. **中介、调节与假设支持**：写清中介路径、调节发生的阶段以及高低水平的条件差异。对不支持的假设、不显著关系和混合结果如实呈现，不将“未达到显著”写成“完全没有作用”。一组显著、另一组不显著不能单独证明组间差异，需核对交互项、差异检验或有调节中介指数等对应证据。假设提出的是差异时，按差异检验判断支持情况。
10. **显著性与时间边界**：按论文采用的阈值与检验结果报告，不把大于 0.10 的 p 值自行称为“边缘显著”，也不将表中的 p=0.000 写成概率恰为零；按其显示精度表述为 p<0.001。对于滞后、持续时间和异质性，逐项核对哪些时点或群体显著、差异是否显著，避免出现“持续三年”与“第三年不显著”之类的概括冲突；原文本身存在歧义时集中备注。
11. **证据强度与解释范围**：观察性数据支持的关联按关联表述，因果措辞须与研究设计及原文证据相符。控制变量或固定效应不代表所有竞争性解释均已排除；作者提出的解释与实际检验的机制分别整理。“仅在某组显著”不等于该关系只能存在于该群体，不从短期指标外推长期绩效或普遍规律。
12. **数字冲突与跨栏一致**：摘要、正文和表格中的同一数字有差异时，先核对样本、模型、指标或四舍五入口径。仍无法解释且影响主要结论时，在集中备注中明确差异，不静默挑选一个数值。同一发现可以在不同栏目承担不同功能，但对象、方向、显著性、效应口径和证据强度须保持一致。

#### 5. 缺失信息与可读性

1. **最终表格尽量不出现“文中未明确说明”“未提及”“未报告”等泛化占位语。** 首先在全文相关位置查找并整合已有信息；不能仅依据摘要或小标题判断缺失。
2. 原文虽没有同名章节，但明确讨论了相关内容时，正常填写该字段。准确概括与跨段落整合均属于允许的整理方式。
3. 某字段只有部分内容时，只写有依据的部分，省略缺失子项。例如作者有姓名但没有机构时只写姓名，方法缺少软件版本时不单独标注版本缺失。
4. 某字段确实没有依据时，保留栏目并将对应单元格留空。不要通过猜测、套用模版示例或机械替换措辞来填满表格。
5. 文件缺失、全文无法获取、扫描或损坏导致关键页面不可读、仅能阅读摘要，以及影响主要结论的数据冲突，属于需要告知的来源或证据问题。应在表格后集中列出“阅读范围与待核对事项”，按文献编号说明具体情况，避免在每个单元格反复提示。
6. 无法阅读全文的文献只能填写已读取部分支持的信息，其余留空，并在集中备注中注明阅读范围。只有存在需要说明的问题时才增加该备注区。
7. 上述规则针对泛化占位语。研究本身的“不显著结果”、作者明确讨论的测量或设计局限仍须如实记录，例如“仅测量行为参与，未覆盖认知和情感参与”。
8. 采用具体、自然的学术中文，减少套话和重复，不使用“不是……而是……”句式，减少破折号。

#### 6. 输出前核对

- 编号是否来自原始文件名，文献与来源文件是否一一对应。
- 表格列名、列顺序、列数、单元格换行和链接是否正确。
- 原始 PDF 是否覆盖全文，是否误将截断的 Excel 文本或既有 AI 解析当作全文依据。
- 样本量、观测单位、变量名称、数据时段、系数类型及效应口径是否与原文一致。
- 方法是否足够具体，主要研究问题是否均有相应发现，重要不显著结果是否保留。
- 多项研究、不同模型、各时点或群体的结果是否分清，差异结论是否有直接检验证据。
- 组织逻辑是否交代研究的递进关系，学术对话是否写出既有观点与本文推进。
- 是否将假设、理论命题、代理指标或作者解释误写成已验证的发现。
- 最终结论是否忠实保留关键不支持结果与适用范围，是否出现“完全决定”“排除所有因素”等超出证据的断言。
- 研究价值、学术对话、局限性、创新性和未来研究方向是否均有原文依据。
- 是否存在重复内容或泛化缺失占位语；确无依据的单元格是否留空。
- 来源或阅读障碍是否已在集中备注中如实交代。

完成后直接输出整理表格及必要的集中备注，不额外添加逐篇解说、内部分析过程或自评。
