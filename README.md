严格要求
1. 所有内容必须严格基于  ，不得引入论文之外的知识、背景资料或个人推测。
2. 论文没有明确提供的信息，统一填写：“文中未明确说明”。
3. 不得为了填满字段而自行推导“创新性”“研究价值”“学术对话”或“未来研究方向”。
4. 必须区分：
    * 核心发现＝研究实际得到了什么结果；
    * 结果阐释＝作者如何解释这些结果；
    * 学术对话＝作者如何把结果与已有研究或理论联系起来；
    * 最终结论＝全文最终得出了什么结论。
5. 核心发现优先保留原文中的关键数据、效应方向、统计结果、主题名称和重要关系，不要只写笼统总结。
6. 如果论文不是实验研究，不要强行使用“实验对象、实验材料”等框架，应根据实际研究类型进行概括。
7. 若论文某一字段存在多个要点，请分点呈现；没有必要为了形式统一而固定条目数量。
8. 输出前再次核对论文，重点检查：
    * 是否出现论文中不存在的信息；
    * 数字、样本量、年份、研究对象是否准确；
    * 是否把作者的讨论或推测误写成研究结果；
    * 是否遗漏论文最主要的研究发现。

#### 4. 研究方法与核心发现的进一步要求

1. **问卷与实验研究**：交代各阶段样本、时间间隔、操纵与分组、主要变量测量、分析模型，以及原文报告的关键中介和调节检验。多项研究分别说明，区分招募样本、有效样本和各模型分析样本。
2. **内容分析与社交媒体数据研究**：交代平台、账号或帖子抽样、数据时段、分析单位、编码维度、编码流程与信度、互动指标及模型。区分 CEO 数量、帖子数量和受众数量，区分点赞、转发、评论等具体指标。
3. **综述与荟萃分析**：交代检索范围、纳入排除标准、研究及样本数量、效应量与合并模型、异质性和偏倚处理，并保留重要亚组结果。
4. **质性研究与理论论文**：分别整理材料、分析过程和主题，或理论基础、概念、命题、机制与边界条件。理论命题表述为“提出”或“预期”，不得写成已得到实证验证的结果。
5. 定量发现采用“变量关系或组间差异＋方向＋关键统计证据＋适用条件”的表达。优先保留与核心结论直接相关的系数、效应量、p 值、置信区间或比例，避免复制整张结果表。
6. 保留原文统计符号的含义。核实 B、b、β 是否标准化，明确相关系数、回归系数和间接效应的区别。保持原文数值精度，不能把未报告的 p 值或置信区间自行计算补入。
7. 中介与调节结果须写清路径、调节发生的阶段以及高低水平的条件差异。对不支持的假设、不显著关系和混合结果如实呈现，不将“未达到显著”写成“完全没有作用”。
8. 观察性数据支持的关联按关联表述，因果措辞须与研究设计及原文证据相符。作者提出的解释与实际检验的机制分别整理。
9. 摘要、正文和表格中的同一数字有差异时，先核对对应样本、模型、指标或四舍五入口径。仍无法解释且影响主要结论时，在集中备注中明确差异，不静默挑选一个数值。
10. 同一发现可在不同栏目服务于不同目的：核心发现报告结果，结果阐释说明作者的解释，学术对话说明与既有研究的关系，最终结论整合回答。避免四栏逐字重复。

#### 5. 缺失信息与可读性

1. **最终表格尽量不出现“文中未明确说明”“未提及”“未报告”等泛化占位语。** 首先在全文相关位置查找并整合已有信息；不能仅依据摘要或小标题判断缺失。
2. 原文虽没有同名章节，但明确讨论了相关内容时，正常填写该字段。准确概括与跨段落整合均属于允许的整理方式。
3. 某字段只有部分内容时，只写有依据的部分，省略缺失子项。例如作者有姓名但没有机构时只写姓名，方法缺少软件版本时不单独标注版本缺失。
4. 某字段确实没有依据时，保留栏目并将对应单元格留空。不要通过猜测、套用模版示例或机械替换措辞来填满表格。
5. 文件缺失、全文无法获取、扫描或损坏导致关键页面不可读、仅能阅读摘要，以及影响主要结论的数据冲突，属于需要告知的来源或证据问题。应在表格后集中列出“阅读范围与待核对事项”，按文献编号说明具体情况，避免在每个单元格反复提示。
6. 无法阅读全文的文献只能填写已读取部分支持的信息，其余留空，并在集中备注中注明阅读范围。只有存在需要说明的问题时才增加该备注区。
7. 上述规则针对泛化占位语。研究本身的“不显著结果”、作者明确讨论的测量或设计局限仍须如实记录，例如“仅测量行为参与，未覆盖认知和情感参与”。
8. 采用具体、自然的学术中文，减少套话和重复，不使用“不是……而是……”句式，减少破折号。

#### 6. 输出前核对

- 编号是否来自原始文件名，文献与来源文件是否一一对应。
- 表格列名、列顺序、列数、单元格换行和链接是否正确。
- 样本量、变量名称、数据时段、系数类型和关键数字是否与原文一致。
- 方法是否足够具体，主要研究问题是否均有相应发现，重要不显著结果是否保留。
- 是否将假设、理论命题或作者解释误写成已验证的发现。
- 研究价值、学术对话、局限性、创新性和未来研究方向是否均有原文依据。
- 是否存在重复内容或泛化缺失占位语；确无依据的单元格是否留空。
- 来源或阅读障碍是否已在集中备注中如实交代。
