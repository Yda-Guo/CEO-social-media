严格要求
1. 所有内容必须严格基于  ，不得引入论文之外的知识、背景资料或个人推测。
2. 论文没有明确提供的信息，统一填写：“文中未明确说明”。
3. 不得为了填满字段而自行推导“创新性”“研究价值”“学术对话”或“未来研究方向”。
4. 必须区分：
    * 核心发现＝研究实际得到了什么结果；
    * 结果阐释＝作者如何解释这些结果；
    * 学术对话＝作者如何把结果与已有研究或理论联系起来；
    * 最终结论＝全文最终得出了什么结论。
5. 核心发现优先保留原文中的关键数据、效应方向、统计结果、主题名称和重要关系，不要只写笼统总结。
6. 如果论文不是实验研究，不要强行使用“实验对象、实验材料”等框架，应根据实际研究类型进行概括。
7. 若论文某一字段存在多个要点，请分点呈现；没有必要为了形式统一而固定条目数量。
8. 输出前再次核对论文，重点检查：
    * 是否出现论文中不存在的信息；
    * 数字、样本量、年份、研究对象是否准确；
    * 是否把作者的讨论或推测误写成研究结果；
    * 是否遗漏论文最主要的研究发现。
